# Car Price Prediction with Machine Learning

## OIBSIP Data Science Project

This project uses machine learning to predict the selling price of used cars.

## Objectives

- Explore the car dataset
- Clean and preprocess the data
- Analyze important features
- Build a machine learning model
- Predict car prices
- Evaluate the model

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
