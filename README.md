# Unemployment Analysis in India

## OIBSIP — Data Analytics Task 2

This project analyzes unemployment data in India to understand unemployment trends across time, regions, and areas.

### Objective

Explore the unemployment dataset, identify patterns and trends, and communicate the main findings using data analysis and visualizations.

### Dataset

The dataset contains unemployment observations for Indian regions, including:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

### Analysis Workflow

1. Load the unemployment dataset.
2. Inspect the data structure and descriptive statistics.
3. Check for missing values and clean the data.
4. Convert the date field into a usable datetime format.
5. Explore unemployment rates across regions and time.
6. Compare rural and urban areas where applicable.
7. Visualize important trends and relationships.
8. Summarize the key findings.

### Files

- `Unemployment Analysis.ipynb` — complete analysis notebook.
- `Unemployment in India.csv` — dataset required by the notebook.
- `README.md` — project documentation.
- `requirements.txt` — Python dependencies.

### How to Run

```bash
pip install -r requirements.txt
jupyter notebook "Unemployment Analysis.ipynb"
```

Make sure `Unemployment in India.csv` remains in the same folder as the notebook.
